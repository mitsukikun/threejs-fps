DUSTLINE is a round-based tactical FPS in the browser: one attacker with a spike against four Sentinel bots on a dusk industrial yard, Site 7. First to 5 rounds takes the match. Plant the spike at A or B, or drop all four Sentinels; earn money each round and spend it in the buy menu on rifles, an SMG, a marksman rifle, grenades and kevlar. Hitscan gunplay with headshots, recoil and spread that punish firing on the move, aim-down-sights, crouching, and bots that patrol, hold angles, investigate gunfire and defuse a planted spike.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser with WebGL 2.
